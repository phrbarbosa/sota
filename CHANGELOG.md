# Changelog

## 1.0.0 — 2026-11-01

First public release.

- **Review**: the Curia council: brief, 5 isolated method-differentiated seats, anonymized triage, targeted contention, external verification, a dimension-by-dimension verdict, a curated version, a dissent register, falsifiers and a pre-mortem.
- **Loop**: rounds of review, fix, release and owner decision, with a checkable criterion, a ledger, guards proven red and explicit stop conditions.
- **Any subject**: profiles for software, writing, plans, decisions, data, prompts, concepts, personal plans, creative work and high-stakes professional domains.
- **Release contract**: invoking the skill never authorizes sending, publishing, deploying or purchasing. The run itself uses your model allowance, and it says how much it will start.
- **Packaging**: Agent Skills format, Claude Code plugin and marketplace, a stdlib validator, and evals.
- **Evals at release**: 4 of 4 cases passed, 2 runs per arm. They check behavior and not review quality. Review quality against a single reviewer has not been measured.
